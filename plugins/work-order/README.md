# work-order

The work-order ticket-as-contract specification, its reference implementation
(`issues.py`), the file binding for tickets stored as Markdown on disk, and the
conformance validator.

## Status

Packaging only (WO-008). The specification text (WO-003), the reference
implementation and file binding (WO-004), and the validator (WO-006) land as
separate pieces of work into this directory.
